# Element TD

Браузерная Tower Defense в духе варкрафтовских карт. Волны идут по лабиринту,
игрок ставит башни шести стихий, качает их и комбинирует. Соло, версус с ботом,
версус и кооп по сети. Работает на ноутбуке и на телефоне.

## Запуск

```bash
npm install
npm run dev          # игра на http://localhost:5173 (без сети)
npm run worker       # сервер комнат + собранная игра на http://localhost:8787
```

Для сетевой игры нужен второй вариант: там же, где статика, живут комнаты.
Аккаунт Cloudflare для локальной разработки **не нужен** — `wrangler dev`
поднимает те же самые Durable Objects прямо на машине.

## Проверки

```bash
npm test             # симуляция и баланс в Node, без браузера
npm run balance      # свод по стратегиям: кто сколько выигрывает
npm run e2e          # браузер: десктоп + iPhone портрет и ландшафт + сеть
npx tsx scripts/trace.ts hard balanced   # разбор одной партии по волнам
npx tsx scripts/tune.ts hard             # подбор экономики перебором
```

`npm run balance` — главный инструмент при правке чисел в `src/core/balance.ts`.
Ориентиры для хардкора: разумная игра выигрывает примерно в трети–двух третях
партий, «качай одну башню» и «много дешёвых башен» — не выигрывают никогда,
случайные ходы — почти никогда. Если эти условия нарушились, баланс сломан,
даже когда числа выглядят правдоподобно.

## Публикация

Нужен бесплатный аккаунт Cloudflare. Один раз:

```bash
npx wrangler login          # откроется браузер
```

Дальше каждый выпуск:

```bash
npm run deploy
```

Команда собирает игру и выкатывает её вместе с сервером комнат на один адрес
вида `https://element-td.<аккаунт>.workers.dev`. Эту ссылку можно давать кому
угодно: комнаты, коды и сеть работают сразу, ничего дополнительно настраивать
не нужно.

## Как всё устроено

```
src/core/     симуляция: не знает ни про экран, ни про браузер
src/ai/       бот и стратегии — они же инструмент проверки баланса
src/render/   рисование на холсте, пиксель-арт генерируется кодом
src/net/      протокол, клиент комнаты, упаковка состояния
src/ui/       экраны, панели, ввод
worker/       сервер комнат: Cloudflare Worker + Durable Object
scripts/      прогоны баланса и разбор партий
```

Главное правило: **`src/core` запускается в Node без браузера**. Благодаря
этому партию можно сыграть тысячу раз за десять секунд и проверить баланс
машинно, а не на глаз. Всё, что тянет за собой DOM, время или картинки,
в `core` попадать не должно.

Второе правило: **симуляция детерминирована**. Никакого `Math.random()` и
`Date.now()` внутри — только генератор от сида, который лежит в самом состоянии.
На этом держатся и повторяемость прогонов, и сетевая игра.

## Сеть

Схема — «хост считает, гость смотрит». Партию симулирует только создатель
комнаты и рассылает снимки состояния десять раз в секунду; второй игрок ничего
не считает, а рисует полученное и отправляет свои команды.

Одинаковую симуляцию у обоих делать нельзя: ноутбук и айфон — это разные
движки JavaScript, они по-разному округляют `Math.pow` и `Math.hypot` в
последнем знаке. В обычном коде это незаметно, а в симуляции ошибка копится, и
через пару минут у игроков получаются разные партии.
